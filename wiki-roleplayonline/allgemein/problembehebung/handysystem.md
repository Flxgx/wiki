# Handysystem

Aufgrund der Vielfältigkeit des Handysystems komplett es vor, dass Spieler vergessen, auch hier Einstellungen vorzunehmen. \
\
Bei Betreten des Servers kommt eine Request Anfrage

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 043629.png" alt="" width="311"><figcaption></figcaption></figure>

Diese Anfrage muss mit drücken der Taste <mark style="color:purple;">F8</mark> -> \[nachfolgend angezeigte Schritte] <mark style="color:green;">akzeptiert</mark> werden



{% hint style="warning" %}
Vor der Nutzung eines neuen Handys, muss man dieses manuell im Inventar öffnen.\
Erst danach funktioniert das öffnen des Handy per F1
{% endhint %}
