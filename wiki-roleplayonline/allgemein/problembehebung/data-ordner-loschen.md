# Data Ordner löschen

Um Probleme vorzubeugen oder ggf. vorhandene Probleme zu beheben, wird bei jedem Update empfohlen, den Data-Ordner zu löschen. Hier erklären wir in kurzen Schritten, wie genau das geht.



{% tabs %}
{% tab title="Schritt 1" %}
Drücke die Windows-Taste und gebe <mark style="color:purple;">FiveM</mark> ein. \
Danach macht du <mark style="color:orange;">Rechts-Klick</mark> auf <mark style="color:purple;">FiveM</mark> und auf <mark style="background-color:purple;">Dateipfad öffnen</mark><br>

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 022427.png" alt="" width="165"><figcaption></figcaption></figure>

oder

* Windows Taste + R gleichzeitig drücken &#x20;
* In das Fenster %localappdata% eingeben und mit Enter bestätigen
{% endtab %}

{% tab title="Schritt 2" %}
Dann wählst du erneut <mark style="color:purple;">FiveM</mark> aus mittels <mark style="color:orange;">Rechts-Klick</mark> und klickst auf <mark style="background-color:purple;">Dateipfad öffnen</mark>

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 022444.png" alt="" width="241"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Schritt 3" %}
Nun klickst du auf <mark style="color:blue;">FiveM Application Data</mark>

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 033315.png" alt="" width="465"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Schritt 4" %}
Jetzt siehst du viele Ordner. \
Da suchst du den <mark style="color:red;">Data-Ordner</mark> und klickst diesen ebenfalls wieder mit <mark style="color:orange;">Rechts-Klick</mark> und auf <mark style="color:red;background-color:red;">löschen</mark>

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 022505.png" alt="" width="453"><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Schritt 5 " %}
<mark style="color:red;">Nachdem der Ordner vollständig im Papierkorb gelandet ist, muss dieser nurnoch geleert werden.</mark>
{% endtab %}
{% endtabs %}

{% hint style="danger" %}
**Warnung**: Während den o.g. Schritten muss FiveM / GTA 5 komplett geschlossen sein!
{% endhint %}
