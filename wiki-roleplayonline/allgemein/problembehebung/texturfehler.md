# Texturfehler

{% hint style="danger" %}
**Warnung**: Für grafische Modifizierungen ist jeder für sich selbst verantwortlich.&#x20;
{% endhint %}

Es kann durchaus vorkommen, dass Texturfehler auftreten, wenn man nicht die richtige Einstellung getroffen hat.\
Wir zeigen dir hier, was zu beachten ist und welche Einstellungen getroffen werden sollten.

{% tabs %}
{% tab title="Grafikspeicher" %}
Zunächst ist es wichtig, dass der Grafikkartenspeicher nicht komplett ausgelastet ist.\
Passe deine Grafikeinstellungen so an, dass der markierte Balken im <mark style="color:green;">grünen Bereich</mark> bleibt.\
So stellst du sicher, dass es dadurch zu keinen Fehlern kommt.

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 031150.png" alt=""><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Extended Texture Budget" %}
In den Einstellungen gibt es die Möglichkeit, den Extended Texture Budget zu ändern.\
Dies sollte immer <mark style="color:red;">mind. auf 75%</mark> stehen. <br>

<figure><img src="../../.gitbook/assets/Screenshot 2025-02-19 021948.png" alt=""><figcaption></figcaption></figure>
{% endtab %}

{% tab title="Texturen laden" %}
Wir haben im Spiel eine Einstellung im Persönlichen Bereich integriert, welche die Texturen nochmals neu laden lässt. Dies hilft meistens, wenn es zu kurzfristigen oder kleinen Problemen kommt.\
&#x20;\- Öffne mit <mark style="background-color:blue;">F3</mark> (sofern nicht anderweitig umgelegt) den <mark style="color:purple;">persönlichen Bereich</mark>\
![](<../../.gitbook/assets/Screenshot 2025-02-19 025951.png>)\
\
\- Klicke auf "<mark style="background-color:blue;">Einstellungen</mark>" und danach auf "<mark style="background-color:blue;">Texturen neu laden</mark>" \
![](<../../.gitbook/assets/Screenshot 2025-02-19 030024.png>)
{% endtab %}
{% endtabs %}



{% hint style="warning" %}
Achtung: Bei der Thematik Extended Texture Budget ist ebenfalls der Grafikkartenspeicher zu beachten, sodass dieser nicht überschritten wird.
{% endhint %}

{% hint style="info" %}
Ebenfalls ist man immer dazu angehalten, in regelmäßigen Abständen, den Data-Ordner zu löschen
{% endhint %}
